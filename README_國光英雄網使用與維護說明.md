# 國光英雄網｜完整專案說明

## 這個版本包含
- `index.html`：可直接在瀏覽器測試的完整前端原型。
- `questions.json`：目前匯入的 521 道題目，含題目、選項、答案、解析、主題、難度、來源年度／年級欄位。年度與年級原始資料未完整標註者明確標示「未標註／待教師確認」。
- `題庫可編輯.csv`：可用 Excel 編輯的題庫。`options` 及 `tags` 欄位以分號分隔。
- `vocabulary.json`、`單字主檔待校對.csv`：從現有題目抽取的英文詞彙候選清單，中文釋義和年級標為待校對，不假裝已經人工核實。
- `110-115/`：原始歷屆題本與答案檔，完整保留。
- 原始 `questions.js`、`questions.xlsx`、教師講義等也保留於專案根目錄；`index.html` 已更新為本版入口。

## 使用方法
1. 解壓縮整包。
2. 雙擊 `index.html` 可先試玩。因為本版題庫已嵌入 HTML，不需外部 CDN 即可測試基本功能。
3. 題庫管理可新增、修改、刪除、匯出 JSON/CSV，或匯入 JSON。
4. 本機修改會存在該瀏覽器的 localStorage；要讓所有學生共用，需匯出題庫 JSON，更新網站部署檔案並重新發布。正式部署建議使用靜態網站主機或校內網站空間。

## 題庫管理規格（重要）
每筆題目欄位：
- `id`：永久唯一 ID，不可重複。
- `type`：`MC` 選擇題或 `TF` 是非題。
- `chapter`：主題名稱。
- `difficulty`：易／普通／難。
- `question`：題幹。
- `options`：選項陣列；CSV 中以分號分隔。
- `answer`：正確答案。建議統一用選項文字，避免選項順序改變造成答案錯置；若使用 A/B/C/D，題目管理人需確保選項順序同步。
- `explanation`：答錯後顯示的解釋。
- `year`：歷屆年度或「自編」。
- `grade`：適用年級。
- `source`：原始題本／自編／教師修改等來源。
- `tags`：額外標籤。

### 單字／句型資料建議
- 單字需建立 `vocabulary_id`，英文、中文、詞性、主題、建議年級、難度、發音文字、來源及校對狀態。
- 句子需建立 `sentence_id`，句子、中文、句型功能、適用情境、建議年級及朗讀文字。
- 每個單字或句型規劃 2–3 道不同題型，但「主題小測」每次每個學習目標只抽 1 題；下次再抽另一題型，減少單調重複。
- 建議題型：英翻中、中翻英、情境選擇、句子填空、聽音選字、句型理解。
- 每個主題頁顯示：學習目標數、題庫總題數、已完成數、待複習數。正式版應以人工維護的 `vocabulary_id`/`sentence_id` 分組，而非只靠題幹文字自動猜詞。

## 435 全能單字王規則（本版預設）
- 435 題，不重複抽題。
- 答對率至少 95%。435 × 95% = 413.25，因此整數答對題數至少為 414 題。
- 目前原始題庫中有 441 道位於「單字」主題的題目，原型會只從這些單字主題題目抽出 435 題；其中包含選擇題與是非題，正式認證前應由教師確認題型是否符合單字熟練度目標，並校對每題品質、年級與答案。
- 本版產生可列印／另存 PDF 的結果頁；本機證書不是伺服器簽發的防偽憑證。若要兌獎，建議正式版加上伺服器成績紀錄、唯一認證編號、已兌獎狀態及教務處核驗介面。

## 歷屆考古題
本版可以按題庫的 `year`、`grade`、`type` 欄位篩選並計分。由於原始 Excel 目前只有 8 個欄位，年度與年級不是逐題欄位，因此目前未能保證每一題都已對應到正確年度／年級。請教師依 `110-115/` 原始 PDF 與答案檔核對後，更新 CSV/JSON。不可把「未標註」題目當成已驗證的考古題。

## 正式上線前的必要工作
1. 由英語教師核對全部答案、題目、解析與中文釋義。
2. 為每題標註年度、年級、題號、來源頁碼／題本。
3. 建立單字和句型唯一 ID，人工確認同一學習目標的 2–3 道題。
4. 建立「435 專用認證題池」，避免把一般是非題或不相關題目混入全能單字王。
5. 在實際手機、平板、電腦測試朗讀、鍵盤操作、字體與無障礙。
6. 若學生要跨裝置保存紀錄及正式兌獎，需後端資料庫、登入或學生識別方式、權限與備份。
7. 確認歷屆考題的校內使用權限與學生個資處理方式。

## 目前限制
這是一個完整可試玩的前端版本，不是已部署到公開網域的網站。學習紀錄和題庫修改保存在本機瀏覽器，無法自動跨裝置同步。朗讀使用瀏覽器語音合成，聲音依裝置與瀏覽器而異。題庫的年度、年級與詞彙中文釋義需校對後才能用於正式認證。
